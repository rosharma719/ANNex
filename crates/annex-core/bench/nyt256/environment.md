# NYT-256 benchmark environment

Use [dataset setup](../../../../docs/data-download.md) and the
[benchmark workflow](../../../../docs/benchmarks.md). Runtime options are listed
by each script's `--help` or in [test configuration](../../../../docs/test-config.md).

Each run must record its actual hardware, toolchain, dependency versions, dataset
checksums, index parameters, query selection, warmup and measurements under the
[benchmark policy](../../../../BENCHMARK_POLICY.md). This file is not an environment
manifest for a current run. Old machine-specific results remain in the Git revision
linked by [historical corrections](../../../annex-multivector/benchmark/RESULTS.md).
