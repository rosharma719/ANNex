# Security policy

## Supported versions

This project is pre-1.0 and does not yet backport security fixes to older
releases. Fixes land on `master` and in the next published version.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub
issues.

Instead, open a private [security advisory][advisory] on the repository. If
that is not possible, report the issue to the repository owner (@rosharma719)
through a private channel on GitHub.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce, ideally with a minimal proof-of-concept.
- Any known mitigations.

You should expect an initial acknowledgement within a few business days. We
will coordinate a fix and a disclosure timeline with you before making
details public.

[advisory]: https://github.com/rosharma719/annex/security/advisories/new
